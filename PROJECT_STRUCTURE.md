# Project Structure

This document provides an overview of the directory structure of the IBM Data Science Capstone Project. Each section explains the purpose of the notebooks and files contained in the project.

## Directory Overview

- **data/**: This folder contains all datasets used in the project. The datasets may include raw data files and processed files.

- **notebooks/**: This directory contains Jupyter notebooks used for analysis and model development. Each notebook serves a unique purpose:
  - `exploratory_data_analysis.ipynb`: This notebook performs an exploratory analysis of the dataset.
  - `data_preprocessing.ipynb`: This notebook includes steps for cleaning and preprocessing the data in preparation for modeling.
  - `model_training.ipynb`: This notebook outlines the training of the machine learning models.
  - `model_evaluation.ipynb`: This notebook evaluates model performance using various metrics and visualizations.

- **scripts/**: This directory holds scripts that can be used for data processing and model training. Each script is modularized into functions for better readability and reusability.

- **requirements.txt**: This file lists all the dependencies required to run the notebooks and scripts.

- **README.md**: This file provides an overview of the project, its goals, and instructions to set it up.

## Conclusion

This structure is designed to keep the project organized and facilitate collaboration, ensuring that each component has a clear purpose.
