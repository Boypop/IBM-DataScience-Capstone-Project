# IBM Data Science Capstone Project

## Project Overview
This project aims to consolidate the learnings from the IBM Data Science Professional Certificate. The goal is to create a comprehensive data science project that utilizes various techniques and methodologies acquired throughout the coursework.

## Key Features
- Data collection and cleaning
- Exploratory data analysis
- Data visualization
- Machine learning model building
- Evaluation of model performance

## Methodologies
The project follows a structured approach that includes:
1. Data Acquisition
2. Data Processing
3. Exploratory Data Analysis (EDA)
4. Model Selection and Training
5. Model Evaluation
6. Deployment of the final product

## Results
The project showcases the results of various analyses, including:
- Statistical summaries of the data
- Visualizations illustrating key insights
- Performance metrics of the machine learning models

## Installation Instructions
To set up the project locally, follow these steps:
1. Clone the repository: `git clone https://github.com/Boypop/IBM-DataScience-Capstone-Project.git`
2. Navigate to the project directory: `cd IBM-DataScience-Capstone-Project`
3. Install required packages: `pip install -r requirements.txt`

## Usage
To run the main script, execute the following command in your terminal:
`python main.py`
