# IBM Data Science Capstone Project

## Overview
This Capstone project is a culmination of the IBM Data Science Professional Certificate program. Its aim is to showcase the skills and knowledge acquired throughout the course.

## Features
- Comprehensive data analysis and visualization.
- Machine learning model development and evaluation.
- User-friendly Jupyter Notebooks.

## Structure
- `data/` : Contains all relevant datasets.
- `notebooks/` : Jupyter notebooks used during the project.
- `src/` : Source code for data processing and model building.
- `README.md` : Documentation of the project.

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Boypop/IBM-DataScience-Capstone-Project.git
   cd IBM-DataScience-Capstone-Project
   ```
2. Install the required libraries:  
   ```bash
   pip install -r requirements.txt
   ```

## Quick Start
- Launch Jupyter Notebook:
   ```bash
   jupyter notebook
   ```
- Open the desired notebook from the `notebooks/` directory and start exploring!

## Notebooks
- `Data_Analysis.ipynb` : Analysis of datasets.
- `Model_Building.ipynb` : Development of machine learning models.
